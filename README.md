# FolderBridge

FolderBridge — отдельное Windows-приложение для безопасной односторонней синхронизации
локальных папок с Google Drive. Оно не знает ничего о FOCTwin или ChatGPT: для других
программ обмен выглядит как обычные файлы на диске.

Текущий домашний пререлиз — **0.1.0b2**. Он предназначен для домашних испытаний до
подключения к реальной установке. В `0.1.0b2` исправлено сохранение новых заданий в
Windows и добавлена собственная иконка FolderBridge для окна, EXE, установщика и трея.

## Что уже умеет

- несколько независимых заданий синхронизации;
- направления `ПК → Drive` и `Drive → ПК`;
- безопасный режим «Копирование»: новые/изменённые файлы переносятся, лишние не удаляются;
- режим «Зеркало»: лишние файлы на Drive отправляются в корзину, локальные — в карантин;
- атомарная загрузка на ПК через временный `.part` и проверку контрольной суммы;
- возобновляемые загрузки больших файлов на Google Drive;
- автоматический повтор после ошибки сети по следующему интервалу;
- локальная SQLite-база заданий, состояния и журнала;
- OAuth Desktop App с Drive-доступом, программно ограниченным корнем `FolderBridge`;
- OAuth-токен и client credentials хранятся через системное хранилище `keyring`
  (на Windows — Credential Manager);
- автозапуск с Windows, фоновая работа и системный трей;
- встроенный менеджер всех GitHub Releases: обновление, переустановка и откат;
- установщик Windows и portable ZIP;
- запуск прямо из клонированного Git-репозитория.

## Как устроен Drive

FolderBridge создаёт на Google Drive собственную корневую папку `FolderBridge`. Для
каждого задания в интерфейсе указывается путь **внутри неё**, например:

```text
FolderBridge/
└── Autotuner/
    ├── to_pc/
    └── from_pc/
```

Для Autotuner рекомендуются два разных задания:

| Направление | Drive | ПК |
|---|---|---|
| команды | `Autotuner/to_pc` | `C:\AutotunerExchange\inbox` |
| результаты | `Autotuner/from_pc` | `C:\AutotunerExchange\outbox` |

Обе пары лучше начать в режиме **«Копирование»**. Двусторонняя синхронизация одной и
той же папки намеренно отсутствует: один файл всегда имеет одного автора, поэтому нет
конфликтов и циклического перезаписывания.

## Первое подключение Google Drive

1. В Google Cloud Console создайте проект и включите **Google Drive API**.
2. В OAuth consent screen добавьте свой аккаунт как test user (если приложение в Testing).
3. Создайте OAuth Client типа **Desktop app** и скачайте JSON.
4. В FolderBridge нажмите **«Подключить Google Drive»** и выберите этот JSON.
5. Разрешите доступ в открывшемся браузере.

Используется scope `https://www.googleapis.com/auth/drive`. Он нужен для направления
`Drive → ПК`: входящий файл может создать ChatGPT, браузер или другой клиент, а
`drive.file` не гарантирует FolderBridge доступ к такому новому файлу. Технически OAuth
даёт доступ ко всему диску, поэтому это явно показывается перед авторизацией. Сам код
FolderBridge ищет, создаёт, изменяет и отправляет в корзину объекты только внутри
корневой папки `Drive/FolderBridge`.

Для домашнего пререлиза достаточно держать OAuth consent screen в режиме **Testing** и
добавить собственный аккаунт в Test users. Google может показать предупреждение о
непроверенном приложении; JSON принадлежит вашему проекту и остаётся только на вашем ПК.
У внешнего приложения в статусе Testing refresh token действует 7 дней, поэтому во время
длительного тестирования Google может попросить подключить Drive заново. Для постоянной
работы OAuth-приложение впоследствии нужно перевести из Testing с учётом требований Google.

OAuth JSON и токены не нужно класть рядом с программой и нельзя коммитить в Git.

## Установка Windows

В GitHub Release доступны:

- `FolderBridge-<version>-setup.exe` — обычный установщик для текущего пользователя;
- `FolderBridge-<version>-windows-x64.zip` — portable-версия;
- `SHA256SUMS.txt` — контрольные суммы.

Установщик не требует прав администратора. Сборка пока не подписана цифровой подписью,
поэтому Windows SmartScreen может показать стандартное предупреждение.

Кнопка **«Версии»** в приложении показывает стабильные и предварительные релизы. Можно
перейти на более новую или старую версию. Установленная версия использует установщик,
portable — portable ZIP. При обновлении portable текущая папка сначала резервируется и
восстанавливается при ошибке копирования.

## Запуск из клонированного репозитория

Windows PowerShell:

```powershell
git clone https://github.com/Granik115/FolderBridge.git
cd FolderBridge
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m folderbridge
```

Либо запустите `run_dev.ps1`: он создаст `.venv`, установит зависимости и откроет
приложение. В режиме исходников кнопка «Обновить clone» делает только безопасный
`git pull --ff-only` и отказывается работать при незакоммиченных изменениях.

## Сборка

На Windows с Python 3.10+:

```powershell
.\build.ps1
```

Скрипт прогоняет тесты и Ruff, собирает onedir-приложение PyInstaller, portable ZIP и,
если установлен Inno Setup 6, установщик. GitHub Actions выполняет тот же процесс для
релизов.

## Ограничения 0.1.0b2

- произвольная уже существующая папка Google Drive пока не выбирается: удалённые пути
  находятся внутри корня `FolderBridge`;
- Google Docs/Sheets/Slides не экспортируются как офисные файлы — синхронизируются
  обычные бинарные/текстовые файлы;
- нет двустороннего merge одного дерева;
- первый запуск требует вручную созданный OAuth Desktop JSON.
